# Community launch kit — Bazik SDK

This file provides factual, reusable copy for introducing this **unofficial** SDK to developers. It does not imply endorsement by Bazik, MonCash or NatCash.

## Short introduction (English)

> Building a Haiti-focused payment integration? This public repository contains an unofficial JavaScript/Node.js SDK for the Bazik API, documenting MonCash payment flows, MonCash/NatCash transfers, and wallet operations. It includes a French getting-started guide, contributor guidelines, and mocked tests. Review the API provider's current documentation before production use. Contributions and constructive feedback are welcome.

Repository: https://github.com/Kencycoeur17/basik-sdk

## Présentation courte (français)

> Vous développez une solution de paiement pour Haïti ? Ce dépôt public propose un SDK JavaScript/Node.js **non officiel** pour l'API Bazik : intégration de paiements MonCash, transferts MonCash/NatCash et opérations de portefeuille documentées. Un guide en français, des consignes de contribution et des tests simulés sont disponibles. Vérifiez la documentation officielle de l'API avant toute mise en production. Les retours techniques et contributions sont les bienvenus.

Dépôt : https://github.com/Kencycoeur17/basik-sdk
